# 补充件：TP 切分与命名判别

> **身份**：本文件是补充件，不是四份原文之一。2026-11-05 从 `test-point-spec` 迁入，作为知识④《测试点生成指南》§二~§四 的团队判别细则与反例补充，与原文配合使用；原文四份只读，口径分歧以§三「裁例通告」的用户裁决为唯一解释（裁决十），本文件据此修订，不改原文。

## 一、切分判别（对知识④§4.1「独立规则」的 PRD 锚定细则）

> 本节全部规则的作用域为**同一测试小类内部**；跨小类的切分以§三裁决十为准。

- **合并规则**：PRD 将多个条件**并列列在同一业务能力、同一小类下**，且没有为它们规定不同的流程、规则、权限或结果 → 合成一条。即使某项可能单独出错，也不因此拆分；该项由 TC 单独覆盖。
- **拆分规则**（仅以下情况拆分）：
  1. 条件属于**不同测试小类**（裁决十，优先判定项）
  2. 条件属于**不同业务能力或不同业务目标**
  3. PRD **明文规定**了不同的流程、规则、权限或结果
  4. **主项与副项**承担不同作用，且 PRD 对两者规定了不同的操作或验收要求
- 字段、数据、角色、控件不同，或其中一项可单独失败——**本身都不是拆分理由**（限同一小类内）。
- **描述不清**：PRD 没说明并列条件是否存在不同规则 → 先按同一目标合并成一条，该模糊点交澄清，**不得自行补造规则**（交接动作的产权与执行见 `test-point-spec`，本节只载判定口径）。

**质检两句话**：

- **该拆**：分属不同测试小类，或两种结果出自 PRD 明文规定的不同流程/规则/权限/结果，或分属不同业务目标 → 拆成两条。
- **该合**：同一小类、同一业务能力下的并列条件、或同一规则下的不同数据/对象/角色 → 合成一条（由 TC 覆盖各检查点）。

**三违规**（作用域：同一小类内）：

1. **太大**：把 PRD 写明不同规则的多条业务塞进一条（如「验证转账功能正确」）；跨小类合并同类违规，按裁决十判
2. **太小**：同一套处理的不同数据拆成多条——若 PRD 对 0 和负数写的是同一套「拒绝并提示」，具体数据是用例的事
3. **耦合**：验证明细检查点的存在性/生效性与其所属能力验证重复 → 只保留能力级验证，细则由 TC 覆盖

## 二、命名补充口径（对知识④§三的团队约定）

格式本身知识④权威：功能级 = `验证`+`操作对象`+`基础功能`；场景级 = `验证`+`跨模块流程描述`（可用"-"串联关键节点）。**裁决十统一格式**：功能级的「基础功能」位改为资料命中的**测试小类名**，逐字取知识②§二 33 个小类（如 `验证新增风险字段校验`、`验证新增风险越权操作`）；场景级 TP 按命中的流程类小类命名。本团队在此之上约定：

- 对象**直接抄 PRD 的叫法**，不自创同义词——名称是未来用例库检索键。
- 短语级（≤30 字），保持同清单内命名风格一致。
- **验证意图词面筛检**（生成端出稿前逐条自查、质检端逐条过一遍——知识④§1.3 禁止项④与 §3.1 语言要求"不出现具体字段名、具体值、处理逻辑和预期结果"的可执行形态）：
  1. **结果词**：不出现「成功 / 不能 / 不可 / 进入…状态 / 自动生成」类词汇（内涵：名称承载"验证什么"的方向，不承载执行能否达成）；
  2. **处理逻辑**：不出现「返回…信息 / 保存到…」类执行过程描述（如"返回需求 ID 与 BRD 协作会话信息"）；
  3. **具体值**：不出现数字字面量与其他具体值（如"25 字符""2-50 个字符"——对应知识④判错示例"验证姓名长度为 2-50 个字符 ❌"）；
  4. **并列双结果谓词**：意图里以「并 / 且」串联两个结果（如"记录日志并自动存档"）必须自查：两结果出自同一套自动留存处理→可合；PRD 规定了不同规则→拆。
  - 例外：PRD 原词照抄场景（对象名/状态名）不因词面命中而判错，按主从裁决与直引证据认定；**小类名原词照抄同样不判错**（裁决十，小类名为名词短语，不触犯上述四类）。

**判错示例**（与知识④颗粒度标准一致的口袋清单）：

| 示例 | 判定 |
|---|---|
| 验证转账功能正确 | ❌ 几条不同业务规则塞一条，没法判（=知识④4.1 过粗） |
| 验证输入 0 元和负数均被拒绝 | ❌ PRD 写的是同一套处理——具体数据是用例的事 |
| 验证系统能转账 | ❌ 功能描述，不是验证（=知识④1.1 功能点≠测试点） |
| 验证需求创建成功后进入待沟通状态 | ❌ 含结果词「成功」+ 状态变更执行结果（=知识④1.3 禁止项④、词面筛检 1） |
| 验证修改标题必填校验与 25 字符长度上限 | ❌ 含具体值 + 字段边界独立成测试点（=知识④3.1 判错示例同类；词面筛检 3） |
| 验证修改标题自动生成默认标题 | ❌ 含处理逻辑「自动生成」（=词面筛检 2） |
| 验证新增标题并返回需求 ID 与会话信息 | ❌ 并列双结果谓词「并」串联两个执行结果，需按合并/拆分规则先判（=词面筛检 4） |
