# AI 运行时工作空间目录结构

> AI 运行前，通过程序逻辑动态创建的工作空间，供 AI 运行时使用。所需资料来源于「物理存储空间」。

## 目录结构

```text
/workspace/
└── runtime_<projectId>/                      # 应用运行时根目录，所有会话共用
    └── file/                                 # 创建工作空间时默认创建
        ├── project-docs/                     # 项目文档目录（BRD/PRD 等，只读）
        │   ├── brd1.md
        │   └── prd1.md
        │
        └── <uuid>/                           # 会话目录（本次流程的过程资料）
            ├── user-input/                   # 本次流程附带的输入资料（用户上传，只读）
            │
            ├── output/                       # 产物目录
            │   ├── tp/                       #   测试点清单
            │   │   └── test-point.md
            │   ├── tc/                       #   测试用例清单
            │   │   └── test-case.md
            │   └── reports/                 #   质检报告
            │       ├── tp-input-check.md    #     测试点资料质检报告（阶段 3）
            │       ├── tp-check.md          #     测试点质检报告（阶段 6）
            │       ├── tc-input-check.md    #     用例资料质检报告（阶段 8）
            │       └── tc-check.md          #     用例质检报告（阶段 11）
            │
            ├── state/                        # 经理独占写
            │   ├── scope-list.md             #   任务功能清单
            │   ├── clarifications.md         #   澄清记录
            │   └── status.md                 #   状态档案
            │
            └── scope/                        # 设计专家独占写
                └── anchors.md                #   溯源锚点底册
```
