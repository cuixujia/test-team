# AI 运行时工作空间目录结构

> AI 运行前，通过程序逻辑动态创建的工作空间，供 AI 运行时使用。所需资料来源于「物理存储空间」。

## 目录结构

```text
/workspace/
└── runtime_<projectId>/                      # 应用运行时根目录，所有会话共用
    └── file/                                 # 创建工作空间时默认创建
        ├── project-docs/                     # 项目文档目录（BRD/PRD 等，只读，纯文本）
        │   ├── brd1.md
        │   └── prd1.md
        │
        └── <uuid>/                           # 会话目录（本次流程的过程资料）
            ├── user-input/                   # 本次流程附带的输入资料（用户上传，只读）
            │
            ├── output/                       # 产物目录
            │   ├── tp/                       # 测试点清单
            │   │   ├── test-point.md
            │   │   └── test-point-table.md   # 数据视图（仅一张表，用户确认载体；主件变更重跑 export_tables 即自动刷新）
            │   ├── tc/                       # 测试用例清单
            │   │   ├── test-case.md
            │   │   └── test-case-table.md    # 数据视图（仅一张表，用户确认载体；主件变更重跑 export_tables 即自动刷新）
            │   └── reports/                  # 机器检查结果与语义质检报告
            │       ├── tp-input-check.md     #   测试点资料质检报告
            │       ├── tp-check.md           #   测试点质检报告
            │       ├── tc-input-check.md     #   用例资料质检报告
            │       ├── tc-check.md           #   用例质检报告
            │       ├── check-tp.json         #   TP 机验报告（2026-11-05 收敛命名；+ .quotes-tp.json 引文明细）
            │       ├── check-tc.json         #   TC 机验报告（含 TC 清单引文逐字；+ .quotes-tc.json 引文明细）
            │       └── check-full.json       #   最终全量兜底结果
            │
            ├── state/                        # 经理独占写
            │   ├── scope-list.md             # 任务功能清单 + 资料角色登记表
            │   ├── clarifications.md         # 澄清记录
            │   └── status.md                 # 状态档案
            │
            └── scope/                        # 资料索引与需求基线
                ├── files-manifest.md         #   纯文本资料指纹清单（Python 侧 sha256）
                ├── outline.md                #   轻扫描：标题树 + 规则编号索引
                └── requirements-baseline.json #  冻结需求基线及直引证据（文件:行号+原话）
```
