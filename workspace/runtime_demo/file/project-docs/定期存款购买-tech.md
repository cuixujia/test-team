# 定期存款购买产品需求文档

## 1. 文档概述

### 1.1 项目背景
本项目旨在为个人客户提供通过网上银行渠道购买定期存款产品的完整功能。当前客户需要通过柜面或手机银行办理定期存款业务，缺少网银渠道的线上化购买能力，影响客户体验和业务转化。

### 1.2 建设目标
- **提升客户体验**：提供便捷的线上购买渠道，减少客户跑网点次数
- **提高销售转化**：通过产品货架展示、筛选排序、试算工具等功能，提升产品浏览到购买的转化率
- **支持营销联动**：实现客户经理推荐人绑定和营销活动触发，增强营销效果
- **完善渠道布局**：补全网银渠道的定期存款购买能力，与其他渠道形成协同

### 1.3 目标用户
已实名认证的个人客户，持有本行有效的借记卡活期账户，通过网上银行渠道办理业务。

### 1.4 技术栈
- Vue 3.5 + Vue Router 4 + Vite 4
- Mock 数据通过 `vite-plugin-mock` 实现
- 路由使用 `hash` 模式
- normalize.css 用于 CSS 重置

## 2. 业务范围

### 2.1 纳入范围
| 功能模块 | 功能说明 | 优先级 |
| --- | --- | --- |
| 产品货架展示 | 展示可售定期存款产品列表，包含产品名称、存期、年利率、起存金额、剩余额度等 | P0 |
| 产品详情查询 | 查看单个产品的详细信息，包括产品说明、利率说明、常见问题等 | P0 |
| 产品筛选排序 | 支持按存期、利率、产品类型等维度筛选；支持按利率高低、主推产品等排序 | P1 |
| 购买试算 | 输入购买金额后实时计算到期利息，展示预估收益 | P0 |
| 付款账户选择 | 选择本人名下状态正常的活期账户作为付款账户，展示可用余额 | P0 |

| 营销联动 | 支持购买后触发抽奖、加息券发放等活动；支持客户经理业绩归属 | P1 |

### 2.2 排除范围（严格遵守）
- 外币定期存款购买功能
- 结构性存款
- 通知存款
- 企业/对公客户的定期存款购买
- 柜面渠道的定期存款购买
- 定期存款支取/提前支取功能
- 定期存款定投（签约式自动购买）功能

### 2.3 产品类型范围
**支持的产品类型：**
- 普通定期存款：整存整取定期存款，支持多种存期（3 个月、6 个月、1 年、2 年、3 年、5 年等）
- 大额存单：面向个人客户的大额存单产品，有额度限制，售罄后不可购买
- 特色定期产品：银行推出的特色定期存款产品，可能有特定客群限制或专属利率

**暂不支持的产品类型：**
- 外币定期存款
- 结构性存款
- 通知存款

### 3.2 页面详细描述

#### 3.2.1 首页 (homePage)
**页面功能：** 作为系统入口，展示各业务模块快捷入口，包括产品浏览、购买记录查询等。

**页面布局：** 顶部为导航栏和用戶信息区，中部为功能卡片展示区，底部为信息区。

**交互功能：** 
- 点击"产品浏览"进入产品列表页
- 点击"我的持仓"进入购买记录页
- 点击用户头像进入个人中心

**视觉元素：** 功能卡片图标、用户头像、账户余额展示、快捷入口按钮。

#### 3.2.2 产品列表页 (productListPage)
**页面功能：** 展示所有可售定期存款产品列表，支持多维度筛选和排序。

**页面布局：** 顶部为筛选条件区（存期、产品类型），中部为产品列表展示区，底部为分页控件。

**交互功能：** 
- 点击筛选条件展开筛选面板
- 选择存期、产品类型进行筛选
- 点击排序按钮切换排序方式（利率从高到低、存期从短到长）
- 点击产品卡片进入产品详情页
- 点击"立即购买"按钮进入购买试算页

**视觉元素：** 产品卡片（产品名称、存期、年利率、起存金额、剩余额度）、筛选标签、排序按钮、分页器。

#### 3.2.3 产品详情页 (productDetailPage)
**页面功能：** 展示单个定期存款产品的详细信息，包括产品说明、利率说明、常见问题等。

**页面布局：** 顶部为产品基本信息区，中部为详细说明区（富文本），底部为操作按钮区。

**交互功能：** 
- 点击"返回列表"返回产品列表页
- 点击"立即购买"进入购买试算页
- 展开/收起产品说明详情

**视觉元素：** 产品标题、年利率大字展示、存期标签、起存金额、产品说明富文本、常见问题列表、购买按钮。

#### 3.2.4 购买试算页 (calculationPage)
**页面功能：** 输入购买金额，实时计算并展示到期利息、执行利率、起息日、到期日等试算结果。

**页面布局：** 顶部为产品信息摘要区，中部为试算表单区（金额输入、存期选择），下部为试算结果展示区，底部为操作按钮区。

**交互功能：** 
- 输入购买金额后自动触发试算
- 选择不同存期实时更新试算结果
- 点击"下一步"进入购买确认页
- 点击"返回"返回产品详情页
- 点击"重新计算"清空输入

**视觉元素：** 金额输入框、存期选择器、试算结果卡片（到期利息、执行利率、起息日、到期日）、下一步按钮。

#### 3.2.5 购买确认页 (confirmPage)

**页面布局：** 顶部为购买信息汇总区，中部为表单区（付款账户选择、金额确认、存期选择、到期处理方式选择），下部为风险提示区，底部为提交按钮区。

**交互功能：**

- 失败时：显示失败原因和建议处理方式

**视觉元素：** 结果状态图标（成功绿色对勾/失败红色叉号）、结果详情列表、操作按钮组。

#### 3.2.7 购买记录页 (purchaseRecordPage)

## 4. 业务流程设计

### 4.1 产品浏览流程
```
首页 → 产品列表页 → 产品详情页 → 购买试算页
         ↓_______________↑
```

**流程说明：**
1. 用户从首页进入产品列表页
2. 在产品列表页浏览产品，可进行筛选排序
3. 点击产品卡片进入产品详情页查看详细信息
4. 从产品详情页可进入购买试算页
5. 可随时返回列表页继续浏览

### 4.2 购买试算流程
```
产品详情页 → 购买试算页 → 购买确认页
                ↓________↑
```

**流程说明：**
1. 用户在产品详情页点击"立即购买"进入购买试算页
2. 在购买试算页输入购买金额，查看试算结果
3. 可调整金额或存期重新试算
4. 确认试算结果后进入购买确认页

### 4.3 购买交易流程
```
购买试算页 → 购买确认页 → 交易结果页 → 购买记录页
                        ↓___________↑
```

**流程说明：**
1. 从购买试算页进入购买确认页
2. 在购买确认页选择付款账户、确认购买信息、选择到期处理方式
3. 阅读并确认风险提示
4. 提交购买申请，系统进行资格校验、余额校验、限额校验
5. 校验通过后调用核心系统执行交易
6. 跳转到交易结果页展示交易结果
7. 成功后可进入购买记录页查看持仓

### 4.4 购买记录查询流程
```
首页 → 购买记录页 → 持仓详情页
```

**流程说明：**
1. 用户从首页进入购买记录页
2. 查看名下所有定期存款持仓列表
3. 点击持仓卡片查看单笔详情

## 7. 业务规则

### 7.1 购买金额规则
- 购买金额不得低于产品起存金额
- 购买金额需符合递增单位要求（如有）
- 购买金额不得超过单户持有上限
- 购买金额不得超过当日累计限额
- 购买金额不得超过转出账户可用余额
- II 类户还需遵守年累计 20 万、日累计 1 万的限额约束

### 7.2 利率规则
- 购买时按银行公示的年利率锁定
- 存续期内不受银行利率调整影响
- 当天买入一般当天起息
- 到期日按"起息日 + 存期"推算

### 7.3 到期处理规则
- 客户购买时需选择到期处理方式：不转存或自动转存
- 不转存：到期后本息自动回到活期账户
- 自动转存：到期后本息按到期日银行挂牌利率自动续存一个相同存期

### 7.4 失败处理规则
- 余额不足：提示缺口金额 = 购买金额 - 可用余额，引导转入资金
- 金额不达标：输入时即时提示
- 产品售罄：明确显示售罄状态，推荐同类在售产品
- 触发限额：明确告知是哪一类限额及剩余额度
- 证件过期：提示需先更新证件
- 系统超时：提示"处理中，请稍后查询"，后台核实后给出准确结果，不得引导客户重试造成重复扣款

### 7.5 合规红线
- 利率必须锁定在合约里，事后不能变
- 关键信息（利率、存期、提前支取规则）必须经客户确认并留痕
- 宣传不能误导，存款产品不能与理财混着展示
- 可疑交易不允许重试，宁可查证也不可重复扣款
- 部分场景要求销售可回溯（双录或视频回溯）

## 8. 非功能性要求

### 8.1 性能要求
- 查询类接口响应时间≤500ms
- 校验类接口响应时间≤500ms
- 交易类接口响应时间≤2s
- 支持峰值并发交易量≥1000 TPS
- 支持峰值并发查询量≥5000 QPS

### 8.2 安全要求
- 所有接口调用必须通过身份认证
- 敏感数据在传输过程中使用 TLS1.2+ 加密
- 同一交易请求必须幂等处理，防止重复扣款
- 所有交易必须生成完整审计日志，保存期限≥15 年

### 8.3 可用性要求
- 核心系统整体可用性≥99.9%
- 关键交易功能可用性≥99.99%
- 故障恢复时间 RTO≤30 分钟，数据恢复点目标 RPO≤5 分钟
