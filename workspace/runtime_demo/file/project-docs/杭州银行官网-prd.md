## 2. 背景与依据

### 2.1 业务背景

杭州银行当前缺少面向公众的官方品牌展示网站（www.hzbank.com.cn），无法对外统一呈现品牌形象、产品介绍、资讯公告、网点信息、人才招聘、投资者关系等关键内容。本次需求旨在从零新建杭州银行官网，作为对外品牌展示与业务办理引导的统一入口（来源：BRD 第一章《一、需求背景》，[BRD](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)）。

### 2.2 依据材料

- 父级 BRD：《业务需求说明书》（需求 ID：2117798616164216833，[BRD](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)），本 PRD 以其中第二章《二、需求目标》、第三章《三、需求范围》、第四章《四、业务流程》及第五章《五、涉及系统与承接范围》中与本次派发任务相关的内容为唯一业务依据。
- 工作空间共享业务资料（业务全景说明、调用链路、数据标准、产品制度、架构关系、历史需求、其他）当前均为空白，未提供可引用依据，本阶段不据此补充任何业务事实。
- 本次派发无存量功能编码（functionIds）关联；BRD 第五章协作边界中提及"网点数据可参考现有网点查询功能的数据源"，但未给出具体功能编码，本 PRD 不编造编码，该事项在后续流程/功能阶段按依赖登记处理。

##### 业务流程

1. 公众用户通过 PC/移动浏览器访问 www.hzbank.com.cn [BRD 四、4.1](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)。

- 业务办理引导入口仅承担跳转职责，交易流程不在官网完成（E1 排除项）。
- 本次实现变化：新建首页模板、Banner/轮播配置管理、主导航结构管理。

### 业务办理引导跳转

#### F08 业务办理引导跳转

##### 业务流程

1. 公众用户在官网首页、产品详情页等业务引导入口点击"开户""贷款申请""理财购买"等按钮 [BRD 四、4.8](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)。
2. 系统识别用户设备类型（PC/移动），按业务类型生成对应的手机银行/网银跳转链接。
3. 用户被重定向至目标渠道对应页面，在目标渠道完成身份认证和业务办理；交易数据不回传官网。
4. 异常：目标页面不可达时由目标渠道自行处理，官网不做额外兜底（E-EX03）[BRD 四、4.8](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)。

##### 业务规则

- 变化类型：**新增**。SYS_WEBSITE 无存量跨渠道跳转能力，需新建（来源：第五章矩阵 F08 行；召回点 R08 结论"无匹配"）。
- 官网仅承担引导职责：识别设备类型 + 生成跳转链接 + 执行重定向；身份认证与业务办理完全在手机银行/网银完成，官网不参与交易流程、不获取用户登录态或交易结果（E1 排除项，NFR03）[BRD 二、需求目标-2](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)、[BRD 五、涉及系统与承接范围](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)。
- 跳转方式采用 HTTP 重定向（302 或前端 location.href），无需 API 对接（D2 边界）。
- 各业务类型（开户/贷款/理财/信用卡等）对应的具体跳转 URL 模板由手机银行/网银团队提供（D2 待确认项）；本功能提供按业务类型配置跳转 URL 模板的能力，URL 模板变更不需发版。
- 设备类型识别规则（UA 判断或其他）待技术阶段确认，本阶段不锁定具体实现。
- 本次实现变化：新建业务引导入口配置管理、设备类型识别、跳转链接生成与重定向执行。

##### 业务对象

| 对象 | 说明 |
| --- | --- |
| 业务引导入口 | 官网上各业务办理引导按钮，含业务类型标识（开户/贷款/理财/信用卡等）、展示位置、文案 |
| 跳转 URL 模板 | 按业务类型 × 设备类型（PC/移动）配置的跳转链接模板，含业务类型参数与来源渠道标识占位 |

##### 业务界面

- 形态：PC Web + Mobile Web 响应式；跳转后进入目标渠道自有页面，官网不自建任何交易界面。

## 7. 系统非功能性约束

### 7.1 语言与地域

- **NFR01 中文版本与面向国内访问**：官网全部页面仅支持中文版本，主要面向国内访问场景，不提供多语言切换能力，验收不要求海外访问性能指标。依据：[BRD 三、3.8](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)、[BRD 二、需求目标-4](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)。适用范围：F01–F08 全部功能及后台管理界面。验证方式：页面文案语种检查；验收用例不含多语言场景。

### 7.2 端适配

- **NFR02 PC 端与移动端响应式适配**：官网所有对外页面需同时适配 PC 端浏览器与移动端浏览器访问，采用响应式设计，同一 URL 下按设备宽度自适应布局。依据：[BRD 三、3.8](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)。适用范围：F01–F08 全部对外页面（含列表页、详情页）。验证方式：主流分辨率（桌面 1920×1080、平板、手机常见机型）走查，布局无错乱、核心交互可用。

### 7.3 交易边界

- **NFR03 不承载在线交易**：官网本身不承载任何在线交易功能，所有业务办理均通过 F08 引导跳转至手机银行/网银完成；官网不得出现账户登录态依赖的交易操作入口。依据：[BRD 二、需求目标-2](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)、[BRD 三、3.8](yjs://ses_e5bb87f3cffeLLd1LHSncwAxVN:brd)（E1 排除项）。适用范围：F01–F08 全部功能。验证方式：全站功能走查确认无交易类操作入口；安全评审确认无交易接口调用。

### 7.4 可用性降级

- **NFR04 客服不可用时的降级展示**：当行内统一在线客服系统不可用时，官网侧展示"客服暂时不可用"提示，同时保留联系电话、邮箱等联系方式，不阻断用户其他浏览行为。依据：PRD 第四章 E-EX02 异常事件定义。适用范围：F07 在线客服入口与联系信息展示。验证方式：模拟客服系统不可用场景，验证降级提示展示且联系信息仍可获取。
