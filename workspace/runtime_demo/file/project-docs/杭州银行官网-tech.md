# 杭州银行官网产品需求说明书

## 1. 文档概述

### 1.1 项目背景

杭州银行当前缺少面向公众的官方品牌展示网站（www.hzbank.com.cn），无法对外统一呈现品牌形象、产品介绍、资讯公告、网点信息、人才招聘、投资者关系等关键内容。本次需求旨在从零新建杭州银行官网，作为对外品牌展示与业务办理引导的统一入口。

### 1.2 项目目标

1. 新建杭州银行对外品牌展示网站，统一承载品牌形象展示、产品信息介绍、资讯公告发布、网点信息查询、人才招聘、投资者关系等面向公众的内容
2. 提供业务办理引导入口，用户点击后可跳转至手机银行/网银等渠道完成交易，官网本身不承载在线交易功能
3. 接入行内统一在线客服系统，支持在线咨询与工单流转
4. 仅支持中文版本，主要面向国内访问，无需多语言及海外性能优化
5. 投资者关系栏目以常规网页形式展示公告、财报等内容，支持 PDF 文件下载
6. 网点及 ATM 查询以静态列表/页面形式展示地址、电话、营业时间等信息，不涉及实时地图交互

### 1.3 目标用户

公众用户（访客），无需登录即可浏览全部公开内容，支持 PC 端和移动端响应式访问。

## 2. 业务模块说明

### 2.1 首页与门户展示（M01）

**功能描述**：作为杭州银行官网的统一访问入口，承载品牌形象与综合信息展示。

**包含内容**：
- 品牌形象 Banner、轮播广告配置与展示
- 主导航结构管理
- 各栏目入口（产品、资讯、网点、招聘、投资者关系、联系我们）
- 业务办理引导入口

**排除内容**：子栏目内部内容展示；在线交易或业务办理流程

### 2.2 产品信息展示（M02）

**功能描述**：向公众静态介绍存款、贷款、理财、信用卡等产品线。

**包含内容**：
- 四大产品线分类浏览（存款、贷款、理财、信用卡）
- 产品详情页展示
- "了解更多/立即申请"引导按钮

**排除内容**：在线购买、签约、申请提交等交易操作

### 2.3 新闻与资讯公告（M03）

**功能描述**：发布并公开展示银行公告、新闻稿、媒体报道等资讯内容。

**包含内容**：
- 按分类（公告/新闻/媒体）浏览
- 关键词检索功能
- 资讯列表页与详情页展示

**排除内容**：投资者关系类合规披露内容的专门处理

### 2.4 网点及 ATM 查询（M04）

**功能描述**：向公众展示营业网点的地址、电话、营业时间、ATM 位置等基础信息。

**包含内容**：
- 网点静态列表展示
- 网点详情信息展示
- 按区域/城市筛选功能

**排除内容**：实时地图交互、距离排序、活动报名、客户经理联系等动态能力

### 2.5 人才招聘与企业文化（M05）

**功能描述**：向求职者和公众展示招聘岗位、企业文化、品牌故事、社会责任等信息。

**包含内容**：
- 岗位列表页与岗位详情页
- 企业文化/品牌故事/社会责任内容页
- 简历投递跳转入口

**排除内容**：简历接收、HR 筛选、面试安排等后端流程

### 2.6 投资者关系（M06）

**功能描述**：向投资者群体以常规网页形式披露公告、财报摘要、ESG 报告等内容。

**包含内容**：
- 投资者关系栏目页
- 分类浏览（公告披露、财报摘要、ESG 报告）
- PDF 文件存储与下载

**排除内容**：监管指定信息披露平台对接；在线投票、股东会议互动等复杂合规功能

### 2.7 在线客服与联系我们（M07）

**功能描述**：为用户提供在线咨询入口和基础联系方式。

**包含内容**：
- 客服悬浮入口调起
- FAQ 列表/详情页
- 联系电话、邮箱等联系信息展示
- 客服系统不可用时的降级提示

**排除内容**：会话管理、坐席分配、工单创建与流转（由统一客服系统承载）

### 2.8 业务办理引导跳转（M08）

**功能描述**：将官网用户的业务办理需求引导至手机银行/网银完成实际交易。

**包含内容**：
- 业务引导入口配置
- 设备类型识别（PC/移动）
- 跳转链接生成与重定向执行

**排除内容**：身份认证、账户操作、交易执行（完全在手机银行/网银完成）

## 4. 数据模型

### 4.1 核心数据实体

#### 4.1.1 产品（Product）
- 产品名称（name）
- 产品类型（type：存款/贷款/理财/信用卡）
- 产品摘要（summary）
- 图文详情（detail）
- 利率/费率说明（rateInfo）
- 引导按钮配置（buttonConfig）
- 发布状态（status：草稿/已发布/已下线）

#### 4.1.2 资讯（News）
- 资讯标题（title）
- 资讯分类（category：公告/新闻/媒体）
- 发布时间（publishTime）
- 摘要（summary）
- 正文内容（content）
- 封面图（coverImage）
- 发布状态（status）

#### 4.1.3 网点（Branch）
- 网点名称（name）
- 所属区域（region）
- 所属城市（city）
- 详细地址（address）
- 联系电话（phone）
- 营业时间（businessHours）
- ATM 位置描述（atmLocation）
- 状态（status）

#### 4.1.4 招聘岗位（Job）
- 岗位名称（title）
- 工作地点（location）
- 职责要求（responsibilities）
- 任职要求（requirements）
- 发布日期（publishDate）
- 投递入口配置（applyUrl）
- 状态（status）

#### 4.1.5 投资者关系披露（InvestorDisclosure）
- 披露标题（title）
- 披露分类（category：公告/财报/ESG）
- 发布日期（publishDate）
- 正文内容（content）
- 关联 PDF 文件（pdfFile）
- 状态（status）

#### 4.1.6 FAQ 条目（FAQ）
- 问题（question）
- 答案（answer）
- 排序（sortOrder）
- 状态（status）

## 5. 业务流程

### 5.1 首页访问流程
```
用户访问 www.hzbank.com.cn → 加载首页 → 展示 Banner/轮播/主导航 → 用户点击栏目入口进入子页面
```

### 5.2 产品浏览流程
```
进入产品介绍栏目 → 查看产品线列表 → 选择具体产品线 → 查看产品列表 → 点击产品详情 → 点击引导按钮跳转手机银行/网银
```

### 5.3 资讯查阅流程
```
进入新闻动态栏目 → 查看资讯列表（可按分类筛选/关键词检索）→ 点击资讯标题 → 查看资讯详情
```

### 5.4 网点查询流程
```
进入网点及 ATM 查询栏目 → 选择区域/城市筛选条件 → 查看网点列表 → 点击网点查看详情
```

### 5.5 招聘应聘流程
```
进入人才招聘栏目 → 查看企业文化内容 → 查看岗位列表 → 点击岗位详情 → 点击投递简历跳转外部平台/邮件
```

### 5.6 投资者关系流程
```
进入投资者关系栏目 → 选择分类（公告/财报/ESG）→ 查看披露列表 → 点击详情或下载 PDF
```

### 5.7 在线客服流程
```
点击客服悬浮按钮/进入联系我们栏目 → 调起统一客服窗口 → 发起在线咨询 → 客服响应处理（必要时生成工单）
```

## 7. 验收标准

### 7.1 功能性验收标准

| 编号 | 验收项 | 验收方法 | 预期结果 |
|------|--------|----------|----------|
| A01 | 首页正常渲染 | PC/移动端分别访问首页 | 页面布局无错乱，Banner、轮播、导航、栏目入口正常展示 |
| A02 | 产品浏览功能 | 依次访问产品列表页和详情页 | 可正常浏览四大类产品线及产品详情 |
| A03 | 业务引导跳转 | 在产品详情页点击引导按钮 | 根据设备类型正确跳转至手机银行/网银对应页面 |
| A04 | 资讯浏览功能 | 访问资讯列表页和详情页 | 可按分类筛选、关键词检索，正常阅读资讯详情 |
| A05 | 网点查询功能 | 访问网点列表页进行筛选 | 可按区域/城市筛选，正常查看网点详情 |
| A06 | 无地图交互 | 检查网点查询页面 | 全站无地图组件、无距离排序功能 |
| A07 | 招聘应聘功能 | 访问岗位列表和详情页 | 可正常浏览岗位信息，点击投递简历正确跳转 |
| A08 | 投资者关系功能 | 访问投资者关系栏目 | 可正常浏览公告/财报/ESG 内容并下载 PDF |
| A09 | PDF 下载功能 | 点击下载 PDF 链接 | PDF 文件正常下载 |
| A10 | 在线客服功能 | 点击客服入口 | 可调起统一客服系统窗口（模拟） |
| A11 | 响应式设计 | 在不同屏幕尺寸下测试 | PC/移动端均正常渲染，布局自适应 |
| A12 | 无交易功能 | 全站功能遍历检查 | 无任何在线交易操作入口 |

### 7.2 非功能性验收标准

| 编号 | 验收项 | 验收标准 |
|------|--------|----------|
| N01 | 语言支持 | 全站仅支持中文，无多语言切换入口 |
| N02 | 访问性能 | 国内访问页面加载时间≤3 秒 |
| N03 | 兼容性 | 主流浏览器（Chrome、Firefox、Safari、Edge）正常渲染 |
| N04 | 降级处理 | 客服系统不可用时展示友好提示，保留联系方式 |

## 8. 限制条件与排除项

### 8.1 明确排除的功能

| 编号 | 排除项 | 说明 |
|------|--------|------|
| E01 | 在线交易功能 | 官网本身不承载任何在线交易，所有业务办理通过跳转完成 |
| E02 | 多语言支持 | 仅支持中文版本，面向国内访问 |
| E03 | 地图交互组件 | 网点查询不支持实时地图交互、距离排序 |
| E04 | 监管披露平台对接 | 投资者关系不对接监管指定信息披露平台 |

### 8.2 跨系统依赖

| 依赖方 | 协作内容 | 边界约定 |
|--------|----------|----------|
| 行内统一在线客服系统 | 官网调起统一在线客服窗口 | 客服系统的会话、坐席、工单能力由其自身承载 |
| 手机银行/网银 | 业务办理引导跳转目标渠道 | 身份认证与业务办理完全在目标渠道完成 |
| 现有网点查询功能数据源 | 网点静态数据来源 | 具体接口/更新方式待依赖阶段核实 |
| 外部招聘平台/企业邮箱 | 简历投递出口 | 简历接收不在官网系统内完成 |
