# 业务需求说明书

## 一、需求背景

杭州银行当前缺少面向公众的官方品牌展示网站（www.hzbank.com.cn），无法对外统一呈现品牌形象、产品介绍、资讯公告、网点信息、人才招聘、投资者关系等关键内容。本次需求旨在从零新建杭州银行官网，作为对外品牌展示与业务办理引导的统一入口。

## 二、需求目标

1. 新建杭州银行对外品牌展示网站，统一承载品牌形象展示、产品信息介绍、资讯公告发布、网点信息查询、人才招聘、投资者关系等面向公众的内容。
2. 提供业务办理引导入口，用户点击后可跳转至手机银行/网银等渠道完成交易，官网本身不承载在线交易功能。
3. 接入行内统一在线客服系统，支持在线咨询与工单流转。
4. 仅支持中文版本，主要面向国内访问，无需多语言及海外性能优化。
5. 投资者关系栏目以常规网页形式展示公告、财报等内容，无特殊合规披露系统对接要求。
6. 网点及 ATM 查询以静态列表/页面形式展示地址、电话、营业时间等信息，不涉及实时地图交互或数据联动。

## 三、需求范围

### 3.1 首页/门户展示
- 官网首页承载品牌形象 Banner、轮播广告、主导航及综合信息展示。
- 提供各栏目入口（产品、资讯、网点、招聘、投资者关系、联系我们等）。
- 支持业务办理引导入口，用户点击后跳转至手机银行/网银完成交易。

### 3.2 产品介绍
- 展示存款、贷款、理财、信用卡等产品线的对外介绍页面。
- 内容以静态图文形式呈现，不涉及在线购买或交易操作。
- 提供"了解更多"或"立即申请"等引导按钮，跳转至对应渠道。

### 3.3 新闻动态/资讯公告
- 发布银行公告、新闻稿、媒体报道等资讯内容。
- 支持按分类（公告、新闻、媒体）浏览和关键词检索。
- 支持资讯列表页和详情页展示。

### 3.4 网点及 ATM 查询
- 以静态列表/页面形式展示营业网点地址、电话、营业时间等信息。
- 不涉及实时地图交互、距离排序或数据联动。
- 可按区域/城市进行筛选查看。

### 3.5 人才招聘/企业文化
- 展示当前招聘岗位列表（岗位名称、工作地点、职责要求等）。
- 展示企业文化、社会责任、品牌故事等面向公众的介绍内容。
- 简历投递入口（可跳转至外部招聘平台或提供邮件投递）。

### 3.6 投资者关系
- 以常规网页形式展示公告披露、财报摘要、ESG 报告等内容。
- 支持 PDF 文件下载。
- 无特殊合规披露系统对接要求，无需对接监管指定信息披露平台。

### 3.7 在线客服/联系我们
- 接入行内统一在线客服系统，支持在线聊天与工单流转。
- 提供常见问题（FAQ）展示。
- 提供联系电话、邮箱等基础联系信息。

### 3.8 通用约束
- 仅支持中文版本，主要面向国内访问。
- 无需多语言支持及海外性能优化。
- 官网本身不承载在线交易功能，所有业务办理均通过跳转至手机银行/网银完成。
- 需适配 PC 端及移动端浏览器访问（响应式设计）。

## 四、业务流程

### 4.1 用户访问官网
1. 用户通过浏览器访问杭州银行官网（www.hzbank.com.cn）。
2. 系统加载首页，展示 Banner、轮播、主导航及综合信息。
3. 用户可通过导航栏或页面入口进入各子栏目。

### 4.2 浏览产品信息
1. 用户从首页或导航进入"产品介绍"栏目。
2. 系统展示产品线列表（存款、贷款、理财、信用卡等）。
3. 用户选择具体产品查看详情（图文介绍、利率/费率说明等）。
4. 如需办理，用户点击"立即申请"或"了解更多"按钮，跳转至手机银行/网银对应页面。

### 4.3 查看资讯公告
1. 用户从首页或导航进入"新闻动态"栏目。
2. 系统展示资讯列表（按时间倒序），支持按分类筛选和关键词搜索。
3. 用户点击标题进入资讯详情页查看完整内容。

### 4.4 查询网点信息
1. 用户从首页或导航进入"网点及 ATM 查询"栏目。
2. 系统展示网点列表，支持按区域/城市筛选。
3. 用户查看网点详情（地址、电话、营业时间、ATM 位置等）。

### 4.5 了解人才招聘与企业文化
1. 用户从导航进入"关于我们"或"人才招聘"栏目。
2. 系统展示企业文化、品牌故事、社会责任等内容。
3. 用户查看当前招聘岗位列表，点击岗位查看详情。
4. 如需应聘，用户点击"投递简历"按钮，跳转至招聘平台或发送邮件。

### 4.6 查看投资者关系信息
1. 用户从导航进入"投资者关系"栏目。
2. 系统展示公告列表、财报摘要、ESG 报告等分类内容。
3. 用户点击标题查看详情或下载 PDF 文件。

### 4.7 在线咨询与联系
1. 用户从页面右下角悬浮按钮或"联系我们"栏目进入在线客服。
2. 系统调起行内统一在线客服窗口，用户可发起在线咨询。
3. 客服坐席响应并处理咨询，必要时生成工单进行后续跟进。
4. 用户也可拨打联系电话或发送邮件进行联系。

### 4.8 业务办理引导跳转
1. 用户在官网浏览过程中，点击"开户""贷款申请""理财购买"等业务引导入口。
2. 系统根据用户设备类型（PC/移动）跳转至对应的手机银行/网银页面。
3. 用户在目标渠道完成身份认证和业务办理。
4. 官网不参与交易流程，仅提供引导入口。
